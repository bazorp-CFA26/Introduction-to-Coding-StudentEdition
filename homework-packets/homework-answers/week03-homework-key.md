### Problem 3 Solution

```python
age = int(input("Age: "))
permission = input("Permission (yes/no): ").strip().lower()
print("Allowed:", age >= 13 and permission == "yes")
```

### Problem 4 Solution

```python
players = int(input("Players: "))

```

### Problem 5 Solution

```python
f = float(input("Fahrenheit: "))
c = (f - 32) * 5 / 9
print("Celsius:", c)
```
